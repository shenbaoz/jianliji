# 即时成品简历结果页设计

## 目标

把“上传简历后的等待”变成唯一的处理阶段。顾客进入结果页时，必须立即看见网站内的专业简历成品，而不是浏览器 PDF 阅读器、临时文件名或二次加载状态。

## 产品规则

1. 结果页不嵌入浏览器原生 PDF 阅读器。
2. 原 PDF 中存在头像时，提取头像并用于网站预览和下载 PDF；没有头像时不凭空生成头像。
3. 默认生成一页、HR 优先的投递版：压缩重复表述与低价值过程，不删除可核实的关键经历、数据、奖项和联系方式。
4. 当一页无法容纳关键事实时，允许两页；禁止为了强制一页而删除关键履历。
5. PDF 生成、头像提取、版式渲染必须在“正在整理”阶段完成。成品页只消费已完成的结果。
6. 不能安全写回原 PDF 时可以换成专业模板，但必须保留真实信息、已提取头像，并明确交付为重新排版的投递版。

## 体验

上传 → 正在整理（单一等待）→ 成品页立即出现：白底 A4 页面、头像、姓名、核心数据、经历与下载按钮。结果页没有 PDF 工具栏，也没有“正在打开”占位。

## 验收

- 沈保自和杜小艳两份 PDF 均能完成：上传、单一等待、立即成品预览、下载。
- 成品页不包含 iframe 或 PDF 查看器工具栏。
- 存在头像的测试 PDF，成品预览与下载 PDF 均显示原头像。
- 生成页数与关键信息由后端验证；一页优先，无法无损压缩时自动两页。
