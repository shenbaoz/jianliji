# 通用简历精修设计

## 目标

将用户上传的旧简历整理为一份通用、可投递的版本。产品服务于同类或相近岗位的多次投递，不要求用户提供某一公司的 JD，不显示匹配分、ATS 分或复杂诊断。

## 产品承诺

- 保留用户原有模板风格、全部图片、头像、背景图、图标和其他视觉资产的位置与尺寸，以及原文件的页数；文字区只可在现有页面内重新排版。
- 不增加粗、着色或其他新的视觉强调样式；统一标题、日期、项目符号和表达风格，删除重复、空泛和明显无效的内容。
- 将已有事实整理为清楚、可面试复述的职责表达；不添加用户未提供的数字、技能、职责、公司或经历。
- 输出的文件必须保留可读文本层，且不得出现文字重叠、页面溢出、关键联系信息缺失或原模板被破坏。

## 用户流程

1. 首页说明“上传旧简历，保留原模板，整理成可投递版本”。
2. 用户上传 PDF、DOCX 或粘贴文字。
3. 系统显示精修进度，不要求填写求职方向、岗位 JD、补充问答或阅读评分报告。
4. 用户在单一完成页查看原版与精修版，并下载精修后的文件。

完成页只保留“原版 / 精修版”切换、逐条修改对比、下载与返回首页。用户可保留原句；不显示“AI 优化”“匹配度”“诊断”或“重新开始”之类的流程分支。

## 精修管线

1. 解析：提取文本、文件页数、页面尺寸、图片位置、文本块与结构化区段；原始文件作为视觉模板基准。
2. 规则整理：清理重复空白、统一常见日期与项目符号、识别标题和经历区块，并标记空泛自评、重复条目和异常长段落。
3. 受证据约束的句级精修：仅针对可定位的经历条目提出替换；每项替换保留原文证据链接，并拒绝无来源新增事实。
4. 模板内重新排版：文字可删除、拆分、合并、改写和重排，以形成明显可见的精修效果；每个页面只能使用原页面的文字区域，固定视觉资产和页数不移动、不缩放、不删除，且不增加粗体等新强调样式。
5. 页面容量控制：内容超出原页面可用空间时，按“删除低价值重复内容 → 压缩表达 → 调整同页文字区分配”的顺序处理；不得新增页面或将内容推入新页。
6. 安全与版式门禁：拦截虚构信息；重新排版后校验文本可提取性、原始页数、固定视觉资产的位置/尺寸、联系方式、重叠、溢出及视觉布局。
7. 回退：任何页面不能安全写入、写入后破坏固定视觉资产、页数或无法验证时，回退原页并在内部记录原因。不得为了完成率破坏简历。

## 内容规则

- 改写只允许：去冗余、拆分长句、统一动作动词、明确已有职责、调整表述顺序和修正明显语病。
- 改写禁止：新增数字、成果、工具、技能、职责范围、团队规模、公司信息、资格或未在原文出现的结论。
- 无明确成果时，保留真实的职责描述，不用虚假量化补齐。
- 普通通用版不依据特定 JD 重排内容；未来的岗位定制仅作为成稿后的可选副本，不影响本流程。

## 文件与异常处理

- DOCX 优先尝试结构化文本重排，保留原有图片、页眉页脚、色彩与字体风格。
- PDF 将原图像/视觉资产作为固定层，按原模板的文字区域在原页面内重新排版；无法保持固定资产或原始页数时停止该页处理并回退。
- 无法提取文本、扫描件、加密文件或不支持的格式返回简洁、可操作的上传提示。
- 仅在用户文件和生成版本的必要保留期内存储；文件访问使用不可猜测且过期的地址。

## 验收标准

- 从上传到下载不出现 JD、评分、岗位匹配、追问或对用户可见的 AI 话术。
- 每一个已应用的改写均能追溯到原简历中的事实，且不会引入被安全门禁禁止的信息。
- 对支持的 PDF/DOCX，精修版保留固定视觉资产、模板风格和原始页数，文本仅允许在原页面内重新排版，并通过文本可提取性和版式完整性检查。
- 精修结果不引入新的粗体、颜色或其他强调样式；固定视觉资产的位置与尺寸在校验中保持一致。
- 无法安全处理的页面自动回退原页；最终文件仍可下载和投递。

## 商用质量门禁

精修成功不能只以模型返回或文件生成成功作为判断，而必须同时满足以下条件：

- 可见价值：至少完成实质性的内容整理，例如删除冗余、自评空话或重复信息，拆解流水账，或将已有职责改写为更清晰的专业表达；仅替换同义词、空格或标点不算精修成功。
- 事实边界：每一项保留或新增到输出中的事实都能追溯到原简历；没有证据时不得补写数据、成果、技能或职责。
- 版式边界：原始页数、固定视觉资产的位置和尺寸、联系方式及可提取文本层均通过校验；不得出现重叠、越界、乱码或空白破损区。
- 可解释性：完成页列出实际删除、合并、改写和重排的条目，让用户能直接看见精修前后的差别。

当任何门禁未通过时，系统不将该输出标记为“已精修完成”；应回退不合格页面或提示该文件暂不支持自动精修，绝不把版式损坏或只做表面同义词替换的文件交付给用户。
- 保留原始文件、精修结果和逐条变更，供完成页对比与版本恢复使用。

## 非目标

- 第一版不提供岗位匹配、ATS 分数、JD 分析、求职信、面试话术、账户订阅或支付。
- 第一版不承诺对所有扫描 PDF、加密 PDF 或任意复杂模板实现无损编辑。
