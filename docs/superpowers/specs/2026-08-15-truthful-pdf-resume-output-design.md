# 真实优化 PDF 成品设计

## 目标

用户提交已有 PDF 简历后，必须获得内容已实际优化的可下载成品。系统不得在没有写入任何改动时，把原文件展示或标记为“整理后”。

## 交付策略

1. 先尝试在原 PDF 模板中安全写回 AI 已确认的改写。
2. 写回至少一处且校验通过时，交付保留原版式的优化 PDF。
3. 原模板无法安全写回时，改用与岗位和候选人类型匹配的原生专业模板生成优化 PDF；不得返回原 PDF 充当成品。
4. 成品页只展示“优化后的简历”和“下载优化版 PDF”。模板选择是可选的“换模板”操作，而非用户必须理解的技术分支。

## 模板

首批提供三种原生模板，均以公开、适合中文求职的开源简历排版为视觉参考，不直接复制其受许可约束的实现：

- HR 经典单栏：默认模板，适合大多数岗位，强调清晰层级和 ATS 可读性。
- 校园求职带照片版：面向应届生、市场、新媒体和活动运营，保留头像与紧凑信息区。
- 现代侧栏版：面向技能、作品链接或技术信息较多的候选人，作为可选模板。

系统根据候选人信息自动选择默认模板；用户可在成品页切换模板，不会触发重新调用 AI。

## 头像与隐私

- 原模板写回成功时，原 PDF 的所有视觉元素（包括头像）原样保留。
- 新模板成品会从原 PDF 中提取可可靠识别的候选人头像并复用，绝不修改人像。
- 未找到唯一可靠头像时，不猜测、不使用其他图片，生成无头像版本并提供用户替换入口。
- 上传文件与导出的临时文件继续遵循现有按期清理机制。

## 状态与错误提示

- 原模板写回成功：显示“已优化，可下载”。
- 已生成新模板成品：显示“已优化，可下载”；不向普通用户暴露“写回失败”等内部细节。
- 无法生成任何真实优化成品：显示明确失败提示，不展示原文件为成品，也不启用下载。

## 测试

- PDF 写回成功时继续保留页数、图片与实际变更记录。
- 写回零处时必须生成包含优化文本的新模板 PDF，并报告成品模式。
- 新模板生成时，原 PDF 中唯一候选头像应保留；存在多个或无法可靠判定的图片时不自动选取。
- 前端仅在后端确认存在真实优化成品时启用下载和“整理后”预览。
