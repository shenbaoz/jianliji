# 简历记

简历记是一个岗位定制简历优化网站。用户先导入简历，再输入目标岗位要求，系统生成岗位匹配分析、证据追问、优化前后对比、模板预览和可导出的简历版本。

当前版本可接入 DeepSeek 进行岗位定制简历优化，并支持可选 Kimi 备用服务。系统会脱敏联系方式、拦截无法从原简历核验的新增数字或工具，并在 AI 不可用或草稿不安全时回退到本地安全初稿。

## 本地运行

第一次运行：

```bash
npm install
npm run dev
```

然后在浏览器打开终端里显示的地址，通常是：

```text
http://127.0.0.1:5173/resume-fit/
```

## 页面说明

- 首页导航：点击进入简历优化流程。
- 简历导入：上传或粘贴简历。
- 目标岗位：粘贴招聘岗位要求。
- 岗位分析：查看匹配度、关键词和问题。
- AI 追问：补充真实经历证据。
- 优化结果：查看修改前后对比。
- 模板导出：编辑简历、选择模板、导出 PDF。
- 我的版本：查看本地保存的简历版本。

## 微信支付

当前版本不接入微信支付。后续接入时，需要在后端创建订单、调用微信支付、验证支付回调，再解锁付费导出或会员功能。前端不能保存微信支付密钥。

## 数据库

后端支持宝塔 MySQL；填写 `.env` 中的数据库配置后，首次启动会自动创建所需表。部署步骤见 [DEPLOYMENT.md](DEPLOYMENT.md)。

后续数据库至少需要保存：

- 用户账号
- 原始简历
- 目标岗位要求
- 岗位匹配报告
- AI 追问问题和用户回答
- 优化后的简历版本
- 模板配置
- 导出记录
- 订单和支付状态
- 后台案例库
- AI 提示词配置

## 案例库原则

网站内置的案例是匿名演示数据，参考公开职业中心简历样例的结构和常见写法，但不直接复制真人简历原文。

这样做有三个原因：

- 避免泄露真实个人信息。
- 避免版权风险。
- 方便按中国求职场景改写成更适合网站演示的数据。
